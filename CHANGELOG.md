# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-14

### Added

- Comprehensive Terms and Conditions in both Spanish and English.
  - Added sections 4-15 covering Inoperable Vehicles, Personal Items, Cancellations, Payments, Insurance, Claims, Liability, Indemnification, Governing Law, Contractual Relationship, and Image Rights.
  - Added "Última actualización" / "Last updated" date.
  - Added navigation side links for all new sections.
- Improved CSS for anchor navigation with `scroll-margin-top`.

### Changed

- Updated package version to 1.0.0.
- Refactored Terms and Conditions page structure.
